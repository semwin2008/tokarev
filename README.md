# Это бот по чату Овса для телеги. По мотивам сглыпы
Доооо
# Требования
- предполагается наличие файла data/result.json в формате экспорта из телеграм в подкаталоге data/ корневого каталога
- предполагается наличие файла .env/TOKEN.txt, содержащего токен бота telegram
# Нужно:
1. Запустить  gather_data.py чтобы собрать датасет в data/text_dataset.csv
2. Запустить solution.ipynb, чтобы обучить модель. (в самом файле настраивается фильтрация данных, base-модель, параметры обучения). По окончании обучения модель сохранится с адаптером в папке model/merged/
3. Запустить main.py - файл бота.
